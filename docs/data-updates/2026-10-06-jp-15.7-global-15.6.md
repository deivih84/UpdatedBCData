# JP 15.7 / Global 15.6 data update

## Sources and published summary versions

- JP data: the locally extracted `15.7.1jp` directory and the retained `にゃんこ大戦争_15.7.1_APKPure.xapk` in BCData.
- Global localization and release notes: `15.6.0en` and `The+Battle+Cats_15.6.0_APKPure.xapk`.
- Release summaries: `update_summaries/jp/15.7.json` and `update_summaries/en/15.6.json`. The global page excludes JP-only 15.7 additions.
- Public and bundled JSON files are byte-identical. Unit IDs match every JP source `unit*.csv` exactly: 882 units, IDs 000–881. Enemy data contains 792 records.

## Import repairs and additional data

JP 15.7 expands SkillAcquisition from 114 to 156 columns. The automation scripts in `Downloads/A/Automatizacion` now preserve existing protected columns while importing the additional slots, and generate all eleven talent slots. The app parses the extended arrays. Talent 71 is an additional health boost; talent 72 reduces production time on every second deployment and has a separate description rather than changing the ordinary recharge statistic.

SkillLevel was synchronized before generation. All 13 existing unit medals were preserved, including Musashi's Ronin's Redemption / icon 66. Evolution enrichment precedes the final asset copy. Production-time reduction is also read from innate stat column 118 so the new rabbit displays its 50% / 75% effect; ordinary recharge remains separate.

Enemy names and descriptions were copied into the language directories used by the JSON builder, and its public output was explicitly enabled. Icons were decrypted from the retained Global and JP game packages and copied to both public images and Android drawables. Newly changed JP unit descriptions were converted to the pipe format consumed by the app. Missing zero-idle backswing values were derived from attack animation duration minus foreswing.

The usual stages script selects Global data. This update used a temporary merged source view: Global files followed by JP mechanics, with existing Global names retained and JP names filling gaps. This includes ZL maps `zl_35` and `zl_36`. The validated result has 22 chapters, 1,010 subchapters, 5,256 stages and 186 continuation links. Existing combo rows were retained, their names reconciled with the source tables, and the two new JP combo rows appended.

## Animation omissions retained as warnings

The incremental animation update created archives 876–881 and modified archives 401, 746 and 754. No archive was replaced wholesale from a partial pack.

Units 877–881 declare third-form rows identical to their evolved-form rows, but their package supplies only first/evolved animations. Their missing `s` forms remain recorded in the animation manifest warnings. Evolved thumbnails are aliased for the declared third forms; no missing animation is fabricated. The spirit record 876 has animation resources but no dictionary thumbnail in the source package.

The final manifest source is JP 15.7.1, matching the game-data version. A second animation dry-run reports no pending sources, no archive changes and **zero changed paths**.
