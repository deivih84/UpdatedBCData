## Verification limits

This checkout's configured BCData and its remote currently contain JP 15.7.1
as their newest extraction, not JP 16.0.0. The original JP 16.0 install package
is also absent. Consequently, `update_cat_animations.py --dry-run` stops with
a version mismatch before planning changes. The public archives can be
checked against their committed manifest and used to reproduce backswings,
but a fresh comparison against the original PONOS 16.0 package is pending.
Do not regenerate the full catalog from the older extraction or describe
this review as a completed game-data synchronization. Retain or restore the
16.0 extraction and incremental installer before repeating that verification.
